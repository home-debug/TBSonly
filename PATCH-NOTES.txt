TBSonly - change package 2026-09-20
=====================================

Contents:
  install_tbsdtv-smart.sh  - main (v18) + hardware detection only
  kernel-patches.sh        - identical to main
  README.md, RELEASES.md   - documentation

This is a minimal-dev package: main build semantics + card detection.
No USB targets, no branch detection, no performance patches, no extra
include paths, no KBUILD_CPPFLAGS, no Module.symvers seeding.

USB support added (2026-09-20, minimal diff to working main+detect):
  - TARGET_DIRS += "usb/dvb-usb" (7 -> 8 targets)
  - Custom Makefile for usb/dvb-usb with all 20 TBS USB modules; object
    names verified against TBS tree (tbs-qbox.c etc.)
  - cleanup() removes the usb Makefile backup
  - Build core untouched: main EXTRA_CFLAGS, main H1/H2, main
    Module.symvers chaining, no KBUILD_CPPFLAGS, no SRC include paths.

Ubuntu user feedback integrated (2026-09-20):
  - TBS 6218 user on Ubuntu 26.04 (kernel 7.0.0): headers are
    linux-headers-x.y.z-a (no -generic), not matched by the -common pattern.
    -> Added fallback: if -common missing, look for linux-headers-${KVER%%-*}*
  - Same user hit "mismatched version errors" until clearing
    /lib/modules/7.0.0-31-generic/updates/ of old modules.
    -> Added optional stale-modules cleanup prompt before install.

Family-filtered build (2026-09-20):
  - detect_tbs_cards now exports DETECTED_FAMILIES (TBSECP3/SAA716x/USB)
  - After detection, TARGET_DIRS is filtered: usb/dvb-usb only if USB
    detected, pci/tbsecp3 + pci/tbsmod only if TBSECP3 detected,
    pci/saa716x only if SAA716x detected. dvb-core/dvb-frontends/tuners
    are always built (shared across families).
  - Empty DETECTED_FAMILIES (detection failed) = build everything (safe).
